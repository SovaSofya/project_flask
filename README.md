# Яд, мудрецом предложенный, прими...
## 1. Общее описание
"Яд, мудрецом предложенный, прими..." -- это приложение, которое принимает на вход слово, вопрос или фразу пользователя, а в ответ выдаёт стихотворение персидского(-таджиксого) поэта из данной базы (на данный момент в ней 491 рубаи Омара Хайяма) по следующему принципу:
  - приложение лемматизирует запрос
  - далее обрабатывает его при помощи модели, взятой с RusVectores (НКРЯ 2019-го года), алгоритмом Word2Vec
  - усредняет вектора слов в запросе (вектора приведены к десятимерным)
  - сравнивает их с такими же усреднёнными векторами стихов из базы (база собрана краулером: вся предобработка, предварительное сохранение векторов, добыча данных и т.д. лежит в тетрадке prework с описанием)
  - выдаёт пользователю стих с наибольшим косинусным сходством усреднённого вектора.
  - может принять у пользователя оценку выданного стиха: "нравится", "не нравится" или "очень нравится", записывая результат в базу.
  - ...и отразить популярность в итоге на странице статистики (и не только её)

В приложении есть:
* страница с описанием и окном запроса
* страница со статистикой: сколько человек воспользовались приложением, топ-10 самых "популярных" (с наивысшим рейтингом в базе) стихов, а такжже количество стихов, в базе помеченных определённой темой в виде bar plot и wordcloud всех стихов в базе.
* в случае если приложение не может векторизовать запрос пользователя, она способна выдать ему предпреждение и предложить сделать новый запрос.
  
**Важно!** Необходимы также следующие модели: 
- https://rusvectores.org/static/models/rusvectores4/RNC/ruscorpora_upos_skipgram_300_5_2018.vec.gz
- https://rusvectores.org/static/models/udpipe_syntagrus.model

Помимо README, это указано в общих reqirements.
## 2. Структура репозитория
main:
- requirements.txt: необходимые модули (и для prework, и для приложения)
- prework.ipynb : предобработка -- создание базы данных, краулер, загрузка моделей, тестирование функций
- flask:
  - app.py: непосредственно приложение
  - templates: html-файлы
  - static
    - images
      - изображения со статистикой, созданные из кода: в коде их создание закомментировано, чтобы ускорить работу (помечено)
